# `feat/mobile-game-ui` 分支 — 完整功能與效果清單

> 此文件盤點 **feat/mobile-game-ui** 分支(至 `392a631`)的所有新增功能/效果,

## 1. 📱 手機遊戲化 UI(Pixel Bonsai 養成體驗)
- 手機直式「舞台」版面:狀態列、標題卡(**Day N** 計數)、📖 日誌(journal)、⚙️ 設定面板。
- **動作列**:Water / Fertilize / Bone Meal 三鍵(圖片像素 icon),各自帶**數量徽章**。
- **日夜時間滑桿**(日出→正午→日落→夜晚),可拖曳調整當天時刻。
- 樹種選擇(settings.species):`cedar` 程序杉樹 / `morph` morph-target 樹。
- 事件 toast + 日誌紀錄(訪客到來、撿到資源、天氣事件…)。

## 2. ⏱️ 遊戲時鐘與生長
- 一天 = `game.dayLengthSeconds`(24 秒),日夜自動推進、太陽弧線連動光照。
- 樹從 Day 1 幼苗長到 **Day 30 全尺寸**(growthDays)。
- 隨機天氣:乾濕交替的陣雨(雨聲、池面漣漪、地面濺雨同步)。
- `skipday30` demo 捷徑:一鍵跳到 Day 30 早晨。

## 3. 🎥 相機
- 滑鼠/手指**拖曳水平環繞**(yaw),texel-snap 防抖。
- **預設取景 yaw 0.85**(池塘在樹的左下)、緩慢**自動環繞**(拖曳後從放開處續轉)。
- **固定特寫構圖**(viewBase 20,樹苗特寫;相機不隨樹長大後拉)+ **倍率制滾輪縮放**(0.45×–2.2×,主迴圈平滑趨近)。

## 4. 🔊 音訊
- **程序化環境音樂** → 升級為**日/夜雙音軌交叉淡化**(`ambiance_music.m4a` / `ambiance_night.m4a`,黃昏/黎明平滑過渡)。
- 雨聲(程序化濾噪)與天氣連動。

## 5. 🐄 動物訪客系統
- **偶發訪客**(不再常駐):動物池輪流入場,沿路線走進來 → **貼著樹吃草**(離樹幹約 1.8–2 單位)→ 待約半天;**晚上不趕客**(過夜),**下雨才提早離開**。
- 到訪 toast 通知(🐄🐑🐶)。
- **糞便系統**:吃草中途會留下 💩(toast 提醒),**點擊撿起 → +1 肥料**。
- **骨粉「收成」**(夜間黑色幽默機制):夜裡點擊訪客 → 牠走向營火(`tofire`)→ 火光爆閃(ember flare)→ **+1 骨粉**(🦴 toast)。

## 6. 💧 資源經濟(三種資源、各有取得方式)
- **水**:初始 1,**點池塘舀水 +1**(水瓢飛向按鈕的動畫);澆水 = 灑水粒子+局部地面漣漪+**生長加速**,無水時擋下並提示。
- **肥料**:初始 1,撿糞便 +1;施肥 = **綠色養分光點從土壤螺旋升入樹冠**(fertilize burst,新特效檔 `effects/fertilize.js`)+1 天生長。
- **骨粉**:初始 1,夜間「收成」+1;使用 +2 天生長,數量徽章顯示。

## 7. 👆 點擊互動(tappable scene)
- **點池塘** → 真實漣漪在點擊處擴散(並觸發舀水)。
- **點樹** → 樹身搖晃 + **樹葉飄落**。
- **快速滑動** → 一陣風(草、葉擺動)。
- 互動目標跟隨當前樹種(`ctx.activeTreeGroup`)。
- 微風常態性吹落零星樹葉(breeze-loosened leaves)。

## 8. 🏞️ 場景/地形
- **池塘重做**:縮小移位(4.4, 6.8;7×5)、**沙質湖岸環**貼著不規則岸線、岸石圈+半沉水石、`rimPoint()` API。
- **山脈環地形**(displaced terrain)取代遠處多面體;**中距離山丘** 8 座補天際線。
- **更寬的草原**(32k 草葉)、加大地面。
- **地平線下裙擺**(內向圓柱)填補畫面最底部,任何環繞角度都不露天空。
- **山丘鋪滿草皮**:`carpetTufts()` 沿實際網格表面(含側坡)灑草叢;**野花點綴山坡**(黃/粉/白/藍,`dropOnto` 落在真實表面)。
- **夜間營火**(雨天熄滅)。

## 9. 🌙 氛圍/渲染
